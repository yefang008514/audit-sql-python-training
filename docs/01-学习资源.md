# 01 学习资源

> 原则：少而精。每个类别挑 1–2 个坚持用，比收藏 50 个有用。

## 一、OJ / 在线练习网站（SQL 刷题）

| 网站 | 地址 | 特点 | 适合阶段 |
|---|---|---|---|
| SQLBolt | https://sqlbolt.com/ | 免费免注册，约 18 个交互式练习，覆盖查询/聚合/多表/子查询，英文但简单 | 入门首选 |
| XUESQL | http://xuesql.cn/ | 相当于 SQLBolt 中文版，上手册下练习，配 B 站免费视频 | 入门（英语吃力选它） |
| SQLZoo | https://sqlzoo.net/ | 老牌免费练习站，多语言（含中文），题目带测验 | 入门→进阶 |
| 牛客网 SQL 题库 | https://www.nowcoder.com/ta/sql | 61+ 道实战题，在线判题，有题解讨论区 | 进阶刷题 |
| LeetCode 数据库 | https://leetcode.cn/problemset/database/ | 可看到自己 SQL 的执行效率排名，能学习别人的优化写法（部分题需会员） | 进阶/面试 |
| w3resource SQL Exercises | https://www.w3resource.com/sql-exercises/ | 题量大、按知识点分类 | 查漏补缺 |
| Mode SQL Tutorial | https://mode.com/sql-tutorial/ | 偏业务数据分析场景 | 数据分析向 |

**Python 练习**：牛客网/LeetCode 也有 Python 题；入门可用廖雪峰 Python 教程（https://liaoxuefeng.com/books/python ）。

## 使用建议

1. **SQL**：SQLBolt/XUESQL 通关 → 牛客网刷 30 题 → 用本仓库第 04 章实战题自测。
2. **Python**：先跟完任意一套入门课的 pandas 部分，然后直接用第 03 章的清洗脚本改着跑。
3. **公众号**：关注「逆行的狗」+「茶瓜子的休闲馆」，看到工具文章就动手复现一次。
